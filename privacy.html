Política de Privacidade

Última atualização: 5 de setembro de 2026

1. Quem somos

O OpenClaw TikTok Publisher é um aplicativo pessoal operado por Ramon Garcia para publicar vídeos em uma conta TikTok autorizada pelo próprio proprietário.

2. Dados tratados

O aplicativo pode tratar os dados necessários para a autorização e publicação, como identificadores básicos da conta TikTok, informações de autorização OAuth, tokens de acesso e os vídeos escolhidos pelo usuário.

3. Como os dados são usados

Esses dados são usados exclusivamente para autenticar a conta autorizada, enviar vídeos e acompanhar o resultado das operações solicitadas pelo proprietário.

4. Armazenamento e compartilhamento

Os tokens e demais credenciais ficam armazenados somente no computador do operador do aplicativo, em ambiente local. O aplicativo não mantém um banco de dados público nem vende, aluga ou compartilha esses dados com terceiros.

Para executar uma publicação, os dados necessários são enviados à API oficial do TikTok. O tratamento realizado pelo TikTok também está sujeito à política de privacidade do próprio TikTok.

5. Retenção e exclusão

Os dados permanecem no computador local apenas enquanto forem necessários para o uso do aplicativo. O operador pode apagar os tokens, vídeos e registros locais a qualquer momento. A autorização também pode ser revogada nas configurações da conta TikTok.

6. Segurança

São adotadas medidas razoáveis para restringir o acesso ao computador e aos arquivos locais. Nenhum método de armazenamento é completamente invulnerável.

7. Contato

Para dúvidas sobre esta política ou sobre os dados tratados, abra uma solicitação no repositório do projeto no GitHub.
